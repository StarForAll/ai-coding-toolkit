- **循环描述**：做菜接单 -> 获得资源 -> 升级餐厅和员工 -> 解锁更高价值订单。

## 2. 分维度策略分析

### 2.1 经济系统 - 评分 5/10

- **锚定依据**：前期生产-消费闭环成立，但第 3 章材料缺口过早出现，接近行业基线下沿。
- **证据状态**：User-provided evidence
- **置信度**：中
- **与品类基准对比**：低于健康模拟经营节奏。轻经营通常需要先建立舒适扩张感，再逐步
  引入规划压力。
- **优势**：做菜、金币、装修和解锁区域的反馈链条清楚。
- **痛点**：材料墙过早，容易让玩家把成长受阻归因到“游戏开始逼我肝或氪”。
- **根因判断**：材料 faucet 偏紧，同时员工效率和推进速度耦合过强。
- **耦合关系**：经济系统 -> 成长养成：材料缺口放大员工星级价值；经济系统 ->
  付费设计：资源紧张提高付费转化，但也提高负面口碑风险。

### 2.2 用户体验与留存 - 评分 4/10

- **锚定依据**：55 分钟日常对轻经营偏重，弱网失败和发热进一步削弱移动端优势。
- **证据状态**：User-provided evidence
- **置信度**：中
- **与品类基准对比**：明显重于碎片化手游的健康区间。
- **优势**：前 30 分钟反馈好，说明基础交互和主题吸引力成立。
- **痛点**：日常全清长、弱网失败、发热，都会影响 D7 留存和通勤使用场景。
- **根因判断**：核心奖励分布过多绑定每日全清，移动端容错设计不足。
- **耦合关系**：UX -> 留存：日常负担直接影响次周活跃；UX -> 社交：公会订单弱网失败会
  让玩家回避社交玩法。

### 2.3 付费设计 - 评分 4/10

- **锚定依据**：180 抽保底 + 每日约 2 抽，在员工星级影响推进时会形成强付费压力。
- **证据状态**：User-provided evidence；概率公示与大小保底为 `[Evidence Gap]`
- **置信度**：中
- **与品类基准对比**：偏高压，尤其不适合“轻松经营”的产品承诺。
- **优势**：装饰皮肤和月卡是更适合模拟经营的健康付费方向。
- **痛点**：限定员工如果影响主线、公会订单和排行榜，玩家会把它理解为变相战力门槛。
- **根因判断**：抽卡价值和推进效率绑定过强，缺少确定性兑换或非付费追赶机制。
- **耦合关系**：付费设计 -> 经济系统：付费资源可缓解材料缺口；付费设计 -> UX：
  付费压力会破坏轻经营放松感。

## 8. 最终策略总结

1. **先守住轻经营承诺**
   - **What**：把核心奖励从 55 分钟全清改为 20-30 分钟主路径。
   - **Why**：轻经营的核心价值是低压力成长，不是日常打卡负担。
   - **Expected impact**：改善 D7 留存和日常完成率。

2. **把抽卡从推进门槛改成效率和收藏选择**
   - **What**：降低早期主线对高星员工的依赖，增加确定性员工成长。
   - **Why**：模拟经营玩家可以接受付费加速，但不接受“不会抽卡就不会经营”。
   - **Expected impact**：降低逼氪投诉，提升零氪和微氪留存。

3. **补齐移动端容错**
   - **What**：优先修公会订单重连、省电和低特效模式。
   - **Why**：手游必须适配通勤、弱网和发热场景。
   - **Expected impact**：提高公会订单参与率和移动场景会话稳定性。
