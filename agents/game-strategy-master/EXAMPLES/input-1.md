# Example Input 1

> 期望输出格式示例输入。以下游戏与信息均为虚构。

游戏名称：星轨餐厅
游戏类型：模拟经营 + 轻度卡牌养成
上线状态：v0.9.3 内测
目标平台：Android，小米 14
当前测试范围：约 6 小时，主线到第 5 章，解锁外卖、员工抽卡、公会订单

核心循环：

- 做菜接单 -> 获得金币和材料 -> 升级餐厅与员工 -> 解锁新菜品和区域 -> 接更高价值订单

关键系统：

- 员工通过抽卡获得，星级影响做菜效率和公会订单加成
- 月卡、战令、限定员工池、装饰皮肤
- 公会订单每日刷新，参与后给稀有材料

测试数据与体验摘要：

- 前 30 分钟完成率高，测试玩家反馈“装修和做菜反馈不错”
- 第 3 章开始材料缺口明显，员工星级差距开始影响推进
- 限定员工池 180 抽保底，内测每日任务大约 2 抽
- 日常全清约 55 分钟
- 公会订单弱网时容易重连失败
- 高画质 20 分钟后手机明显温热

分析诉求：

- 深度分析
- 重点看留存、付费公平性、日常压力和移动端体验
- 需要给出新的有效游戏策略和 1-6 月版本路线
