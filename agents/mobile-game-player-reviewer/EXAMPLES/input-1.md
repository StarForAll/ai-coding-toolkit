# Example Input 1

> 期望输出格式示例输入。以下游戏与信息均为虚构。

游戏名称：星轨餐厅
游戏类型：模拟经营 + 轻度卡牌养成
游玩平台：Android，小米 14
当前版本号：v0.9.3 内测包
已游玩时长：约 6 小时，主线到第 5 章，解锁外卖、员工抽卡、公会订单
付费模式：免费 + 内购，含员工抽卡、月卡、装饰皮肤
重点关注：

- 新手期是否好懂
- 抽卡会不会逼氪
- 日常任务是否太肝
- 发热和掉电是否影响通勤游玩

补充体验：

- 前 30 分钟很上头，装修和做菜反馈不错
- 第 3 章开始升级材料卡住，员工星级差距明显
- 限定员工池 180 抽保底，内测每日任务大约 2 抽
- 日常全清约 55 分钟
- 公会订单弱网时容易重连失败
- 开高画质 20 分钟后手机明显温热
