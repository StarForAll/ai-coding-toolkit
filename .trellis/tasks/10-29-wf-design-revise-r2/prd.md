# PRD：按第二轮审查修正 wf-framework-design.md

## Goal

以第二轮审查判断（A–F + 可吸收点 1–3）为依据，整体重写 `docs/workflows/wf-framework-design.md`（非补丁式），修正按字面实现会落错东西的定义级缺陷。

## Requirements

### 修正项（第二轮判断，逐条对应）

- **A（高）挂起清除判据回正源语义**：§5.6 步 5 判据由"返工来源为 T 的任务全部已正常归档"改回源设计（workflow-design.md §6.4 第 5 步）的"**返工集合非空 ∧ 无未归档成员**"（正常归档的异常归档 R 均不再计入未归档成员，集合非空防真空真值）；替换/放弃返工任务 R 的实施步骤补"继任者继承返工来源"（替换与放弃-新建替代两变体）；启动校验（§5.4）补"挂起 ⇒ 返工集合非空"组合识别（对应源设计类型 2）。同步核查所有"无泄漏路径"声明的口径。
- **B（高）审查目录与参数对齐全局 skill 实际契约**：**保留 `review/round-{N}/` 目录约定**（用户裁决），适配清单明确列出"目录路径由全局 skill 的 `review-round-{N}` 变更为 `review/round-{N}`"，承认该变更为**非加性**；删除/改写全部"同形/无需为 wf 改动"的错误声明（§2.2、§6.5、§8）；reviewer 命令参数集统一为完整五参（`--task-id`、`--task-dir`、`--reviewer-id`、`--round`、`--review-focus`），消除 §4.1 与 §6.5/§8 两版口径（F 项）；`--task-id` 写 frontmatter（不从目录名推断）、`--task-dir` 承担路径解析的分工保持。
- **C（中）审查 fail 处置路径补全**：`fail` → 段内回退就地修 → 重跑 Check → 下一轮（就地修复不耗轮次）；2 轮仍 `fail` → 人确认发起返工，**挂载点 = 本任务自身**（返工挂载点定义由"未归档前置任务"放宽为"未归档任务"，含本任务，与源设计语义一致）；返工完成后审查轮次重置。
- **D（中低）"写者纪律与 git 历史无矛盾"的判据落地**：入口脚本写入时在任务记录留**写入标记**（写入者 + 命令 + 提交指纹，字段形状落 §8 机制文档清单）；启动校验该项判据 = "判定字段的变更提交携带写入标记，缺标记即按无标记越轨报告"；§8 落点清单补此项。
- **E（中低）登记同仓生命周期冲突**：§2.2 已知外部依赖处补一句：workflow-implementation.md §8.5.7 计划在内嵌模块内部版落地后删除全局 `multi-cli-review*`；若该计划先行执行，本框架 P0 适配对象消失，须重接（vendor 自有对 / 改适配内嵌契约 / 保留全局），裁决落 authoring 侧。
- **F（低）reviewer 命令参数两版合一**：并入 B 项处理。

### 吸收项（第二轮判断第五节 1–3）

- 完成判据补"证据须对最终状态仍有效"（stop-that-shit Ladder 第 5 步丢掉的半句）：Check 受控取值记录附工作区/提交指纹，指纹不符视为无证据（结构性做法，防"改完代码旧绿灯过门禁"）；
- 非法 glob 按条失效：`paths` 校验拒绝绝对路径与 `..` 时，仅该 spec 条目失效并进 WARN 清单，不废整份 spec（沿 Trellis spec_match.py validate_glob 粒度）；
- fail-closed 门禁的负向测试：验收纪律补"wf 自建门禁、repair、安装器每个 fail-closed 行为须有一条会红的测试"（沿同仓 workflow-implementation.md 探针纪律）。

### 回扫清单补强（第二轮判断 §6.3）

§1.3 回扫四对象之外补三类证据面：被压缩掉的源条件（与 workflow-design.md 源判据并排核对）、外部资产的实际约定（读被依赖 skill 的实际 SKILL.md）、状态 × 操作矩阵（每个状态字段 × 归档/替换/放弃/删边交叉核对）。

### 不变项（本轮裁决的边界）

- 不偏离四条核心需求与硬边界（无 hook、无团队、无子代理派发、无平台分支、skill 为核心）；
- 仅并入本轮判断项（A–F + 吸收 1–3 + 回扫补强）与存量项目基线/git 前提（上一轮 P0、本轮判断未覆盖的真缺口，镜像新项目既有通道约 3 行）；其余上一轮 P1/P2 改进项**不并入**，留待后续任务；
- 骨架不动：调用权分层、写者纪律、单一记录、三时点拉取、诚实分级、依赖语义概念集全部保留；
- 不修改 skills/multi-cli-review*（适配是 authoring 侧后续任务，本任务只改设计文档）。

## Acceptance Criteria

- [ ] A：挂起清除判据、R 被替换/放弃两路径、"挂起⇒集合非空"校验项三处一致，全文无残留的旧判据表述；
- [ ] B/F：全文只剩一套目录约定（review/round-{N}/）与一套五参命令口径，"加性适配"声明已按非加性改写，三处"同形/无需改动"声明清除；
- [ ] C：fail 处置路径完整（就地修/轮次/2 轮出口/自我返工挂载点）且与 §5.6 返工定义一致；
- [ ] D/E：写入标记有判据有 §8 落点；同仓删除冲突已登记；
- [ ] 吸收 1–3 与回扫三类证据面已写入对应章节；
- [ ] 交叉回扫：机制名登记（§1.3）、门禁唯一定义（§6.5）、路由位置（§4.1）、术语一致（返工集合/挂起/指针等）核对无漂移；
- [ ] 修正不引入新矛盾：源判据语义（非空∧无未归档成员）、目录契约、fail 出口三个修正点全文交叉一致；
- [ ] 人工审查通过前不执行收尾（不提交到 git、不归档、不更新 spec）。

## 非目标

- 不实现机制文档与代码（§8 后续工作不动，除补写入标记与门禁负向测试落点）；
- 不修改全局 multi-cli-review* skill；
- 不处理上一轮审查的 P1/P2 改进项（切分判据、复盘形状、spec 准入第三门槛等）。
