# Normative Rules

* If a project maintains both `README.md` and `README.en.md`, the pair must be treated as a linked documentation set rather than independent files.
* In the default bilingual baseline, `README.md` must remain the default Simplified Chinese entry unless the project explicitly adopts another documented language policy.
* Any change to root README content, structure, commands, paths, links, setup steps, status descriptions, or other user-facing project facts must update both `README.md` and `README.en.md` in the same change.
* The paired README files must keep visible cross-links near the top so readers can switch languages directly.
* A project must not silently let one README variant drift from the other on repository purpose, setup flow, structure, or operating instructions.
* If a project intentionally diverges from the default bilingual baseline, the replacement policy must be documented explicitly in the project-level spec set instead of being implied by partial file edits.
