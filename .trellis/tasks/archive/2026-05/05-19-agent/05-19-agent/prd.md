# 优化大众玩家游戏评论Agent提示词

## Goal

基于 `tmp/大众玩家游戏评论Agent.md` 设计文档，输出一份**可直接使用的 System Prompt** 和配套的**用户调用模板**，用于分析手机游戏APP的优劣，为游戏改进提供玩家视角的建议。

## What I already know

### 已确认的设计决策

- **输出文件**：`tmp/大众玩家游戏评论Agent-SystemPrompt.md`（新文件，原文档保留为设计参考）
- **Shot Example**：虚构游戏——"一款三国题材的放置卡牌手游"
- **输出结构**：两层分离——(A) System Prompt（直接可用） + (B) 用户调用模板
- **角色设定**：压缩为 3-4 句核心约束，删除原文档中的三段人群展开描述；评估时自然带出人群特征
- **长度控制**：亮点/痛点各限制 TOP 5，超出部分可列为"其他可提及项"
- **示例**：加入 1 个完整 shot example
- **付费维度**：补充 pay-to-win / pay-to-progress / cosmetic-only 三种模式判断
- **输出语言**：仅中文
- **竞品对比**：结构化分析（而非简单提一句）
- **交互模式**：支持迭代对话（多轮追问），不是一次性报告
- **敏感内容**：直接点出风险（赌博机制/擦边球等）
- **评价方式**：纯定性评价，无打分机制
- **清理**：去掉原文档中"请设计""你必须包含"等元层指令
- **使用形态**：不在此任务中定义（忽略）

### 从原文档保留的核心要素

- 8+ 评估维度（含手机端专属维度：耗电发热、弱网可玩性、推送骚扰度、单手操作适配）
- 痛点按影响程度排序，标注"普遍问题"vs"个人膈应"
- 建议含开发成本标注（低/中/高）、流失视角分析
- "如果我是策划最想优先改的三件事"总结
- 玩家真心话收尾

## Requirements

1. System Prompt 可直接复制使用，无需额外编辑
2. 用户调用模板清晰定义输入信息格式
3. 包含 1 个完整 shot example 展示期望的语气和深度
4. 所有从原文档保留的评估维度需整合进 System Prompt
5. 付费模式需细分为 pay-to-win / pay-to-progress / cosmetic-only 判断
