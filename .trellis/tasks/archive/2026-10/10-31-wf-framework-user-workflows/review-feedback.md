## 用户本轮已裁决

- 仅定义中声明可略的步骤可经人确认略过；必需步骤须以有效产物满足，或改流程另建实例。
- 终止时预览并批量放弃未完任务，同时允许人选择保留；人明确放弃的任务不必先完成原前置、返工或检查。
- 支持准备定义通道，随后人确认启动实例；准备写入仍受单写入权约束。
- 保留任务独立接续是上述选择的落地方式：任务唯一记录保存许可，仍保留原实例历史归属；另一实例不能收养它。

## 设计推演（非运行验收）

| 路径 | 核对结果及边界 |
|---|---|
| 空项目→首份定义→初始化→业务任务 | 准备不要求已有任务；创建不要求基线/配置；首个任务仍获批准后自举；后续读取实际产物 |
| 定义草稿非法或准备取消 | 可保留明确草稿并释放准备写权，不能创建实例；不把格式修完当作退出前提 |
| 初始化任务建立测试命令再用于 Check | 当前任务 Plan 先声明，建立设施后消费；不能用未来测试结果满足自身开工门禁 |
| 必需 LICENSE 动作发现合格既有文件 | 验证符合当前要求后复用满足，不伪造新写入/测试、不免除任务四阶段 |
| 可略步骤尚未生成任务 | 人确认省略及下游替代，下一任务依赖前一个未略过且正常完成任务，不指向不存在的任务 |
| 可略步骤已生成任务后放弃 | 先落实任务放弃及改动处置，再记略过；下一步骤不新增对异常归档任务的依赖 |
| 必需任务失败/放弃 | 修复/继任者继续当前实例，或走异常终止；不会无限等待一个无法满足的步骤且无退出 |
| 终止时放弃挂起 T、保留返工 R | T 可取消其等待并异常归档；R 保留来源/历史，依赖合法就可在新会话独立继续，不强制先清完返工才能放弃 T |
| 保留执行中但已回 Plan 的任务 | 按任务状态加暂停，不能因为阶段 Plan 将执行中重写为未开工 |
| 保留任务后续发生返工/替换 | 新任务按普通任务建立，只保存来源，不重新加入已结束实例；旧历史归属不变 |
| 批量终止中断/未提交许可 | 持久检查点只补未完成动作；停止决定仍冻结业务，处置/持久化未完不冒称全部终止成功 |
| 源定义改错字、改方案、主动迁移 | 前两者保持旧快照执行；只有主动采用新语义走退出/新建，旧任务不被新实例重新认领 |
| 多次重入自动建任务/建边 | 按实例/步骤映射核对已有记录，补齐原动作；不重复生成任务，也不跨任务复用开工批准 |

上述为同会话逐条对照条款的设计推演；没有启动框架或模拟真实宿主，不构成测试通过、独立 reviewer 或跨会话行为证据。
