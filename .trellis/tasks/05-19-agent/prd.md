# 游戏策略大师 Agent 系统提示词

## 目标

基于 `tmp/游戏策略大师Agent提示词.md`（元提示词），生成一份可直接使用的"游戏策略大师 Agent"系统提示词（System Prompt）。

## 需求确认

| 维度 | 决策 |
|---|---|
| 目标用户 | 游戏公司内部策略/策划团队，用于自研产品的诊断和优化决策 |
| 分析深度 | 支持快速诊断卡片 + 全面深度分析两种模式，由用户选择 |
| 品类范围 | 全品类通用（RPG/SLG/MOBA/卡牌/休闲/二次元/模拟经营等） |
| 产物形态 | 元提示词指导生成可用的 system prompt，内置品类自适应框架 |

## 优化方向（6 项）

1. **品类差异化框架** — 根据品类动态调整维度权重和分析子维度
2. **输入信息模板** — 内置结构化输入格式，提升信息采集效率
3. **分步分析流程（CoT）** — 核心循环理解 → 逐系统分析 → 交叉验证 → 综合策略 → 优先级排序
4. **评分锚定标准** — 每个维度定义 1-10 分锚点，确保评分可比
5. **手游特有维度** — 触屏交互、碎片化体验、体力系统、抽卡机制等
6. **策略综合层（Synthesis）** — 跨维度耦合分析、交叉影响矩阵

## 产物

1. 优化后的元提示词（更新 `tmp/游戏策略大师Agent提示词.md`）
2. 基于元提示词生成的可直接使用的 system prompt（写入新文件）
