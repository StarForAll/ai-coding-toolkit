# wf-framework-design 唯一定义索引表（最小可用版，消费点列经机器生成 + 人确认）

> **语义**：本表是 `wf-framework-design.md` 全部"唯一定义"条目的机器可读登记——**定义**（名称 + 定义落点章节）、**消费点**（引用该判据的章节）、**再定义点**（以"初始化 / 追加 / 特例"方式接触该量的语句；**常态为"无"，出现即须回收到定义公式内**——正文 §8 第 1 项）。
> **用途**：①正文 §1.3 登记表**⑦行"变更影响面自问"**的反查落点（既有命令语义变更时按消费点列反查受影响条款）；②机检器（`scripts/validate-wf-design.py`）的输入之一。
> **维护纪律（防双事实源 + 防静默缺项）**：①定义列与正文"唯一定义"标记**双向核对**（机检器执行）；②**消费点列 = 机器生成候选 + 人确认**——机检器按匹配键（定义名"（"前主词）扫描正文出现章节，与消费点列求差，非空即 FAIL；**匹配键必须逐字出现在正文**（定义名命名时即保证），键匹配不到的行会低估消费点、由人在确认时补正；③**排除标注**：机器候选中的同名异义项（如"本文档自身 frontmatter"≠ skill frontmatter）由人否决，以"排除：§X=理由"登记在消费点列内——排除项的章节号随行入检，语义是"人已确认的非消费点"，防止下一轮重新怀疑；④索引只是指针，不复制规则正文（与 §6.1 index 三段式同律）。
