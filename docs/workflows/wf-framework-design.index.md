# wf-framework-design 唯一定义索引表

本表只定位规则，不复制定义。定义列定位所有者章节；词面候选列由正文逐字检索生成；语义消费点列由修订会话对照实际步骤/判据人工标注，独立于词面生成。两列都是修改时的反查输入，不互相替代。

核对状态只取三类：“未核对”表示未做语义检查，语义列写“待核对”；“已核对·有消费”必须给出节号与消费理由；“已核对·仅定义节”表示逐节检查后未发现跨节消费，语义列写“仅定义节（附理由）”。禁止用空白或“无词面命中”冒充后两类。r4 基线已经人工审查通过；r5 及后续修订新增的词面候选与语义消费点由当轮修订会话核对，尚待人工复审。两种核对都不构成框架运行或端到端验收。

`validate-wf-design.py` 目前机械验证：章节与 § 引用可解析、两文档定义不得重名、索引行可解析且定义位点已登记、charter 行核对第五列 `charter Tn` 指针并报“悬空消费”、已迁入 charter 的条目关键词不得回流、charter 条目在 §8.2 有带标签的场景行、§8.2 三档断言表的表头与逐行完整性（表格列数只接受 3 或 4）。100% 命中与结构全绿只证明这些机械关系成立，不证明第五列的语义完整，也不证明三档表覆盖了全部语义边界。

再定义点常态为“无”；重复构造要收回正文的定义处。词面同名异义的排除按“排除：§章节=原因”登记，语义反查不靠词频推断。索引条数随真实定义变化，不为命中率凑条目。
