# wf-framework-design 唯一定义索引表

本表只定位规则，不复制定义。定义列定位所有者章节；词面候选列由正文逐字检索生成；语义消费点列由修订会话对照实际步骤/判据人工标注，独立于词面生成。两列都是修改时的反查输入，不互相替代。

核对状态只取三类：“未核对”表示未做语义检查，语义列写“待核对”；“已核对·有消费”必须给出节号与消费理由；“已核对·仅定义节”表示逐节检查后未发现跨节消费，语义列写“仅定义节（附理由）”。禁止用空白或“无词面命中”冒充后两类。r4 基线已经人工审查通过；r5 修订新增的词面候选与语义消费点由本轮修订会话核对，尚待人工复审。两种核对都不构成框架运行或端到端验收。

`validate-wf-design.py` 目前只机械验证章节/定义与第三列的词面候选，100% 命中不证明第五列的语义完整。检查未覆盖的同义消费要靠第五列反查与场景推演；新增/改变门禁、状态、指针、记录或资产时必须重核这些语义条目。若将来自动更新候选，只替换第三列，不能清掉第五、六列。未核对的关键条目不得宣称已完成变更影响核对；“已消费”必须反向定位正文中的实际动作，只有预期依赖而无动作时应补正文或撤销标注，不得按意图填表。

再定义点常态为“无”；重复构造要收回正文的定义处。词面同名异义的排除按“排除：§章节=原因”登记，语义反查不靠词频推断。索引条数随真实定义变化，不为命中率凑条目。
