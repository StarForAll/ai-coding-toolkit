# Verification

Check the following:

* selected test layers match the actual regression risk
* critical behaviors have a clear verification owner
* cross-layer changes are not under-tested
* manual-only checks are justified and explicit
* test strategy limitations are documented as evidence gaps when needed
* tests remain automatic, repeatable, and independent of execution order
* high-risk behaviors receive stronger coverage expectations than incidental code
* correct cases, boundaries, invariants, and error paths are covered intentionally
